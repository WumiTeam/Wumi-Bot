# Security

Found a vulnerability in Wumi? Please **don't open a public issue**.
Contact the team privately on the [support server](https://discord.gg/VaGrXgnAHS) (open a ticket or DM Wumi to reach the modmail).

Never share your `.env` file or your bot token. If a token leaks, reset it immediately in the
[Discord Developer Portal](https://discord.com/developers/applications).
